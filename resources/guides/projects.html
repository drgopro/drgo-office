프로젝트 관리 사용법

상담부터 세팅·납품·결제·잔금까지, 프로젝트의 진행 단계를 관리하는 방법을 안내합니다.

1프로젝트 목록 화면

목록에는 진행 중인 프로젝트가 표시됩니다(취소된 건은 기본 제외). 상단에 검색·필터·주요 버튼이 있습니다.

  • 검색: 의뢰자명 · 프로젝트명으로 찾습니다. ↺ 초기화로 조건을 지웁니다.
  • 필터: 단계 · 유형 · 태그(대분류/소분류)로 좁혀 봅니다. 체크하면 바로 적용됩니다.
  • 컬럼: 프로젝트명 · 의뢰자 · 유형 · 단계 · 담당자 · 시작일. 의뢰자와 연동 안 된 건은 (의뢰자 없음) · 확인불가로 표시됩니다.

상단 버튼: + 새 프로젝트 · 💸 잔금 관리 · 엑셀 가져오기. 목록은 최근 생성순, 20건씩 표시됩니다.

2새 프로젝트 만들기

상단 + 새 프로젝트를 누르면 생성 창이 열립니다.

  1. 의뢰자를 검색해 연결합니다. 아직 등록 안 된 고객이면 의뢰자명 확인 불가를 체크하고 이름만 직접 적어 만들 수 있습니다(나중에 연동 가능).
  2. 프로젝트명과 유형을 정합니다(필수). 필요 시 규모(개인/스튜디오/기업/렌탈/방송룸)와 작업 유형, 개요를 입력합니다.
  3. 생성을 누릅니다. 생성하면 단계는 상담부터 시작하고, 등록한 본인이 담당자가 됩니다.
💳
단순 결제 프로젝트 토글을 켜면 상담·단계 없이 결제 내역만 관리합니다. 생성 후 결제 입력창이 바로 열립니다(예: 단순 상품 판매·입금 기록).

3프로젝트 유형 · 작업 유형 · 규모

프로젝트는 유형에 따라 진행 단계가 달라집니다. 기본 유형은 다음과 같습니다.

문의 원격 방문 내방 촬영 제작 렌탈 방송룸 상품 A/S 문제 해결

작업 유형(세팅·원격·답사·촬영중계·디자인·A/S·파견·월 계약·시간 대여)과 규모(개인·스튜디오·기업·렌탈·방송룸)를 함께 지정해 성격을 구체화합니다.

⚙️
유형·단계 구성은 관리자 화면에서 바꿀 수 있습니다. 유형별 단계는 아래 진행 단계를 참고하세요.

4진행 단계(스테이지)

프로젝트 상세 위쪽의 진행 단계 바에서 현재 단계를 확인하고, 단계를 눌러 진행합니다. 단계는 유형마다 다릅니다. 주요 유형의 흐름은 다음과 같습니다.

방문

상담→일정제안→견적/계약→결제/예약→방문세팅→완료

원격

상담→진단→일정제안→견적/결제→원격처리→완료

촬영

상담→일정제안→사전답사→견적/계약→결제→촬영→완료

제작(디자인)

상담→견적/계약→결제→제작/컨펌→납품→완료

내방 · 방송룸 · 렌탈

상담→일정제안→(견적)→결제→이용→완료

문의 · 상품 · A/S · 문제 해결

접수/상담→(진단)→처리/진행→완료
🖱️
단계를 누르면 그 단계의 성격에 따라 창이 열립니다 — 일정제안→일정 연결 창, 견적/계약→견적 창, 결제→결제 창, 완료→완료 확인. 그 외 단계는 창 없이 바로 넘어갑니다.

5프로젝트 상세 화면

상세 상단에는 의뢰자·유형·규모·담당자·시작일이 있고, 우측에 📋 로그 ✏️ 프로젝트 수정 취소 삭제 버튼이 있습니다. 아래로 여러 카드가 이어집니다.

카드용도
의뢰자 정보 / 개요 / 태그연결된 고객, 프로젝트 개요, 대분류·소분류 태그.
📅 일정 제안연결된 캘린더 일정 요약. 편집으로 일정을 연결하면 캘린더와 양방향으로 이어집니다.
📝 견적/계약연동 견적서 링크와 메모.
🛠 방문 보고서서식 있는 에디터(제목·목록·표·이미지·템플릿). 완료 후 작성.
상담 이력상담 등록으로 수단(카카오톡/전화/내방상담/현장답사)·결과(대기/유효/무효/완료)·내용 기록.
피드백 / 문서 / 추가 정보내부 피드백, 문서 업로드, 관리자 정의 맞춤 항목.

6결제 내역

💰 결제 내역 카드의 + 결제 추가로 입금을 기록합니다.

  • 견적서 연결: 연동하면 견적 항목이 결제 항목으로 자동 채워집니다.
  • 금액 · 결제일 · 결제 수단(카드/현금/계좌이체/기타) · 수기 항목 · 메모를 입력합니다.
  • 환불 · 결제 취소: 결제 건에서 ↩ 환불(선택 항목/금액) 또는 ⚠ 결제 취소(전액)를 처리합니다. 환불액은 남은 결제액을 넘을 수 없습니다.
🧾
결제 내역 카드는 결제가 없어도 항상 표시됩니다. 등록된 결제 내역이 없습니다. 우측 상단 [+ 결제 추가]로 기록

7청구 · 잔금 관리

아직 못 받은 돈은 청구로 등록해 추적합니다.

  • 결제 입력 시 💸 청구로 등록을 켜면 받을 금액이 청구로 남고 입금을 추적합니다.
  • 결제에서 잔금을 체크하면, 남은 금액이 자동으로 청구(미입금)로 생성됩니다.
  • 결제 내역 카드에 💸 청구 / 입금 / 잔금과 입금 기록 완료 처리 버튼이 표시되고, 미입금 / 부분입금 배지로 상태를 봅니다.
🔄
자동 계산: 입금이 쌓이면 청구 상태가 미입금 → 부분입금 → 완료로 자동 갱신되고, 결제 저장 시 단계가 결제보다 앞이면 결제 단계로 자동 진행됩니다(결제 단계가 있는 유형만).

8잔금 관리 화면

목록 상단 💸 잔금 관리를 누르면 미입금·부분입금 청구를 모아 봅니다.

  • 컬럼: 의뢰자 · 프로젝트 · 청구일(경과일) · 청구액 · 입금액 · 잔금 · 최근 입금일 · 상태.
  • 상단에 총 미수 잔금 합계 · 건수가 표시됩니다.
  • 잔금이 남아 있어도 완료 처리로 수동 종결할 수 있습니다.

남은 청구가 없으면 ✅ 잔금이 남은 청구가 없습니다.가 표시됩니다.

9프로젝트 취소 · 삭제

상세 우측 취소를 누르면 취소 창이 열립니다. 사유(의뢰자 연락 두절 / 의뢰자 사정 / 일정 불일치 / 기타)를 고르고 취소 처리합니다.

⚠️
취소는 데이터는 보존되며, 단계만 '취소'로 변경됩니다. 반면 삭제는 프로젝트를 완전히 지웁니다. 기록을 남기려면 취소를 사용하세요.

10권한

권한가능한 작업
열람 권한목록·상세·잔금 관리 보기, 결제·요약·일정 조회, 문서 열람.
편집 권한생성·단계 변경·수정·삭제, 피드백, 결제 저장/수정/삭제/환불, 청구 생성/수정, 문서 업로드.

유형·맞춤 항목 정의 변경은 관리자 권한이 필요합니다.

?자주 묻는 질문

단계가 안 넘어가요.

단계는 유형별 흐름에 있는 단계만 이동할 수 있습니다(완료·취소는 언제든 가능). 유형에 맞는 다음 단계인지 확인하세요.

결제를 기록했는데 단계가 자동으로 바뀌었어요.

정상입니다. 결제를 저장하면 현재 단계가 결제보다 앞일 때 결제 단계로 자동 진행됩니다(결제 단계가 있는 유형에 한함). 문의·A/S 등은 결제만 기록되고 단계는 유지됩니다.

의뢰자를 아직 등록 안 했는데 프로젝트를 만들 수 있나요?

네. 생성 창에서 의뢰자명 확인 불가를 체크하고 이름만 적어 만들 수 있습니다. 나중에 실제 의뢰자와 연동하면 됩니다.

잔금이 계속 남아 있는데 끝내고 싶어요.

잔금 관리 화면 또는 결제 카드에서 완료 처리로 수동 종결할 수 있습니다(입금이 다 안 됐어도 가능).

취소한 프로젝트가 목록에서 사라졌어요.

목록은 기본적으로 취소 건을 숨깁니다. 단계 필터에서 취소를 포함하거나 검색으로 찾을 수 있고, 데이터는 그대로 보존됩니다.
